# 📈 Stock Price Prediction using TCN-Transformer Hybrid

This project predicts stock prices using a hybrid deep learning model that combines **Temporal Convolutional Networks (TCN)** and **Transformer** architecture. It uses historical market data and technical indicators to forecast future stock prices.

## 🚀 Features
- Real-time stock data via `yfinance`
- Feature extraction using technical indicators from `ta`
- Hybrid model using TCN + Transformer layers
- Achieved **98% R² score**
- Visual output of predicted vs actual prices
- Optional Streamlit app for interactive UI

## 🧠 Tech Stack
- Python
- TensorFlow or PyTorch
- yfinance
- ta (technical analysis indicators)
- Streamlit
